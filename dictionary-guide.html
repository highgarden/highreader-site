User dictionary: JSON & CSV guide

In Settings → User dictionaries, add a dictionary, enter a name (for example, “Essential 1,000 words”), and choose the original and meaning languages. Select a JSON or CSV file. These settings belong in the app, not in the file.

Fields

original and meaning are required, non-empty text. example is an optional sentence. type is optional: word or idiom. If omitted, an original containing whitespace is classified as an idiom; otherwise it is a word. Keep field names in English exactly as shown, regardless of your selected languages.

JSON format

Save a UTF-8 .json file containing an array of objects. Do not add comments or trailing commas. The example uses English originals and Korean meanings; replace the text with your chosen languages.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
Download JSON example

CSV format

Save as CSV UTF-8 (.csv) with a comma separator and a header row. original and meaning columns are required; example and type columns may be omitted. Put values containing commas, quotation marks or line breaks inside double quotes. Write a quotation mark inside a quoted value as two quotation marks. Spreadsheet apps usually handle this when exporting as CSV UTF-8.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
Download CSV example

Import checks

Use a file no larger than 10 MB and no more than 20,000 entries. Empty originals or meanings and duplicate originals within one file are rejected. Duplicate matching ignores case and normalizes whitespace. Correct the file and import it again.

Managing your dictionary

Open a dictionary to search and edit entries. You can rename it, enable or disable it, replace its file, or delete it. Enabled matching user dictionary entries take priority over built-in dictionary entries on pages, and your dictionary name appears as the source.

사용자 사전 JSON·CSV 등록 가이드

설정 → 사용자 사전에서 사전을 추가하고 이름(예: “초등 필수 단어 1000”)과 원문 언어·뜻 언어를 선택한 뒤 JSON 또는 CSV 파일을 고르세요. 이름과 언어는 파일이 아닌 앱에서 설정합니다.

입력 항목

original(원문)과 meaning(뜻)은 비어 있지 않은 필수 문자열입니다. example(예문)은 선택입니다. type은 word(단어) 또는 idiom(숙어)이며 생략할 수 있습니다. 생략하면 원문에 공백이 있는 항목은 숙어, 나머지는 단어로 분류합니다. 선택한 언어와 관계없이 필드 이름은 예시의 영문 그대로 사용하세요.

JSON 형식

객체 배열을 담은 UTF-8 .json 파일로 저장하세요. 주석이나 마지막 항목 뒤 쉼표는 넣지 마세요. 예시는 영어 원문·한국어 뜻이며, 선택한 언어에 맞게 내용을 바꾸면 됩니다.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
JSON 예제 다운로드

CSV 형식

쉼표로 구분하고 첫 줄에 열 이름이 있는 CSV UTF-8(.csv) 파일로 저장하세요. original·meaning 열은 필수이며 example·type 열은 생략할 수 있습니다. 값에 쉼표, 큰따옴표, 줄바꿈이 있으면 전체를 큰따옴표로 감싸세요. 그 안의 큰따옴표는 두 번 겹쳐 적습니다. 스프레드시트에서 CSV UTF-8로 저장하면 보통 자동 처리됩니다.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
CSV 예제 다운로드

등록 전 확인

파일은 최대 10MB, 항목은 최대 20,000개입니다. 원문·뜻이 비어 있거나 한 파일 안에 중복 원문이 있으면 등록되지 않습니다. 중복 확인 시 대소문자를 구분하지 않고 공백을 정규화합니다. 파일을 수정한 뒤 다시 등록하세요.

사전 관리

사전을 열어 항목을 검색·수정할 수 있습니다. 이름 변경, 사용 여부 설정, 파일 교체, 삭제도 가능합니다. 페이지에 같은 단어·숙어가 있으면 사용 중인 사용자 사전을 기본 사전보다 우선 적용하고 등록한 사전 이름을 출처로 표시합니다.

ユーザー辞書：JSON・CSV登録ガイド

設定 → ユーザー辞書から辞書を追加し、名前（例：「必須単語1000」）と原文・意味の言語を選び、JSONまたはCSVファイルを選択します。名前と言語はファイルではなくアプリで設定します。

入力項目

original（原文）とmeaning（意味）は空でない文字列が必須です。example（例文）は任意です。typeはword（単語）またはidiom（熟語）で、省略できます。省略時は原文に空白を含む項目を熟語、それ以外を単語とします。項目名は選択言語に関係なく例と同じ英語で記載してください。

JSON形式

オブジェクトの配列をUTF-8の.jsonファイルとして保存します。コメントや末尾の余分なコンマは使えません。例は英語の原文と韓国語の意味です。選択した言語の内容に置き換えてください。

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
JSONの例をダウンロード

CSV形式

コンマ区切りで1行目に列名を記したCSV UTF-8（.csv）として保存します。originalとmeaningは必須で、exampleとtype列は省略できます。コンマ、二重引用符、改行を含む値は二重引用符で囲み、その中の二重引用符は2つ重ねます。表計算アプリのCSV UTF-8出力では通常自動処理されます。

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
CSVの例をダウンロード

登録前の確認

ファイルは最大10MB、項目は最大20,000件です。原文・意味が空の場合や、同じファイル内に原文の重複がある場合は登録できません。重複の判定では大文字・小文字を区別せず空白を正規化します。修正して再登録してください。

辞書の管理

辞書を開いて項目を検索・編集できます。名前変更、有効・無効の切り替え、ファイル差し替え、削除も可能です。ページでは有効なユーザー辞書の一致項目を標準辞書より優先し、登録した辞書名を出典として表示します。

Dictionnaire personnel : guide JSON et CSV

Dans Réglages → Dictionnaires personnels, ajoutez un dictionnaire, saisissez un nom (par exemple « 1 000 mots essentiels »), choisissez les langues des originaux et des définitions, puis un fichier JSON ou CSV. Le nom et les langues se règlent dans l’application, pas dans le fichier.

Champs

original et meaning sont des textes obligatoires non vides. example est une phrase facultative. type est facultatif : word ou idiom. Sans type, un original contenant des espaces est classé comme expression, sinon comme mot. Conservez les noms de champs en anglais tels quels, quelle que soit la langue choisie.

Format JSON

Enregistrez un tableau d’objets dans un fichier .json UTF-8, sans commentaires ni virgule finale. L’exemple contient des originaux anglais et des définitions coréennes ; remplacez-les par vos langues.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
Télécharger l’exemple JSON

Format CSV

Enregistrez en CSV UTF-8 (.csv), avec des virgules comme séparateurs et une ligne d’en-tête. Les colonnes original et meaning sont obligatoires ; example et type peuvent être omises. Entourez de guillemets doubles les valeurs contenant des virgules, guillemets ou sauts de ligne. Doublez les guillemets à l’intérieur. Les tableurs le font généralement lors de l’export CSV UTF-8.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
Télécharger l’exemple CSV

Vérifications

Limites : 10 Mo et 20 000 entrées. Les originaux ou définitions vides et les originaux en double dans un même fichier sont refusés. La détection ignore la casse et normalise les espaces. Corrigez le fichier et réimportez-le.

Gestion

Ouvrez un dictionnaire pour rechercher et modifier ses entrées. Vous pouvez le renommer, l’activer ou le désactiver, remplacer son fichier ou le supprimer. Sur les pages, les correspondances d’un dictionnaire personnel actif sont prioritaires sur le dictionnaire intégré et affichent le nom de votre dictionnaire comme source.

Eigenes Wörterbuch: JSON- und CSV-Anleitung

Fügen Sie unter Einstellungen → Eigene Wörterbücher ein Wörterbuch hinzu. Geben Sie einen Namen ein (z. B. „1.000 Grundwörter“), wählen Sie die Sprachen für Original und Bedeutung und eine JSON- oder CSV-Datei. Name und Sprachen werden in der App festgelegt, nicht in der Datei.

Felder

original und meaning müssen nicht leere Texte enthalten. example ist ein optionaler Beispielsatz. type ist optional: word oder idiom. Ohne type gilt ein Original mit Leerraum als Redewendung, sonst als Wort. Verwenden Sie unabhängig von der Sprache genau die englischen Feldnamen.

JSON-Format

Speichern Sie eine Liste von Objekten als UTF-8-Datei mit der Endung .json, ohne Kommentare oder abschließende Kommas. Das Beispiel enthält englische Originale und koreanische Bedeutungen. Ersetzen Sie diese durch Ihre gewählten Sprachen.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
JSON-Beispiel herunterladen

CSV-Format

Speichern Sie CSV UTF-8 (.csv) mit Kommas als Trennzeichen und einer Kopfzeile. original und meaning sind Pflichtspalten; example und type können entfallen. Werte mit Kommas, Anführungszeichen oder Zeilenumbrüchen müssen in doppelte Anführungszeichen eingeschlossen werden. Verdoppeln Sie innere Anführungszeichen. Tabellenprogramme erledigen dies beim CSV-UTF-8-Export in der Regel automatisch.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
CSV-Beispiel herunterladen

Prüfung beim Import

Maximal 10 MB und 20.000 Einträge. Leere Originale oder Bedeutungen und doppelte Originale innerhalb einer Datei werden abgelehnt. Groß-/Kleinschreibung wird ignoriert und Leerraum vereinheitlicht. Korrigieren Sie die Datei und importieren Sie erneut.

Verwaltung

Öffnen Sie ein Wörterbuch, um Einträge zu suchen und zu bearbeiten. Sie können es umbenennen, aktivieren oder deaktivieren, die Datei ersetzen oder es löschen. Auf Seiten haben passende Einträge aktiver eigener Wörterbücher Vorrang vor dem integrierten Wörterbuch; der Wörterbuchname wird als Quelle angezeigt.

Diccionario personal: guía de JSON y CSV

En Ajustes → Diccionarios personales, añade un diccionario, escribe un nombre (por ejemplo, «1.000 palabras esenciales»), elige los idiomas del original y del significado, y selecciona un archivo JSON o CSV. El nombre y los idiomas se configuran en la app, no en el archivo.

Campos

original y meaning son textos obligatorios y no vacíos. example es una oración opcional. type es opcional: word o idiom. Si se omite, un original con espacios se clasifica como expresión; en caso contrario, como palabra. Usa los nombres de campo en inglés exactamente como se muestran, independientemente del idioma.

Formato JSON

Guarda una matriz de objetos en un archivo .json UTF-8, sin comentarios ni comas finales. El ejemplo contiene originales en inglés y significados en coreano; sustitúyelos por los idiomas elegidos.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]

Formato CSV

Guarda como CSV UTF-8 (.csv), separado por comas y con una fila de encabezados. original y meaning son obligatorios; example y type pueden omitirse. Encierra entre comillas dobles los valores que contengan comas, comillas o saltos de línea. Duplica las comillas interiores. Las hojas de cálculo suelen hacerlo al exportar como CSV UTF-8.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom

Comprobaciones

Máximo 10 MB y 20.000 entradas. Se rechazan originales o significados vacíos y originales duplicados en un mismo archivo. La detección ignora mayúsculas y normaliza espacios. Corrige el archivo e impórtalo de nuevo.

Gestión

Abre un diccionario para buscar y editar entradas. Puedes cambiar su nombre, activarlo o desactivarlo, reemplazar el archivo o eliminarlo. En las páginas, las coincidencias de diccionarios personales activos tienen prioridad sobre el diccionario integrado y muestran el nombre del diccionario como fuente.

Coloque entre aspas duplas os valores com vírgulas, aspas ou quebras de linha. Duplique as aspas internas. Planilhas normalmente fazem isso ao exportar como CSV UTF-8.

original,meaning,example,type

Verificações

Máximo de 10 MB e 20.000 entradas. Originais ou significados vazios e originais duplicados no mesmo arquivo são rejeitados. A comparação ignora maiúsculas e normaliza espaços. Corrija o arquivo e importe novamente.

Gerenciamento

Abra um dicionário para pesquisar e editar entradas. Você pode renomeá-lo, ativá-lo ou desativá-lo, substituir o arquivo ou excluí-lo. Nas páginas, correspondências de dicionários pessoais ativos têm prioridade sobre o dicionário integrado, e o nome do seu dicionário aparece como fonte.

Пользовательский словарь: JSON и CSV

В разделе Настройки → Пользовательские словари добавьте словарь, укажите название (например, «1000 основных слов»), выберите языки оригинала и значения, затем файл JSON или CSV. Название и языки задаются в приложении, а не в файле.

Поля

original и meaning — обязательные непустые строки. example — необязательный пример предложения. type — необязательное поле: word или idiom. Без него оригинал с пробелами считается выражением, а без пробелов — словом. Сохраняйте английские имена полей в точности независимо от выбранного языка.

Формат JSON

Сохраните массив объектов в файле .json в кодировке UTF-8, без комментариев и лишней запятой в конце. В примере оригиналы на английском, значения на корейском; замените их текстом на выбранных языках.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
Скачать пример JSON

Формат CSV

Сохраните CSV UTF-8 (.csv) с разделителем-запятой и строкой заголовков. original и meaning обязательны; example и type можно опустить. Значения с запятыми, кавычками или переносами строк заключайте в двойные кавычки. Внутренние кавычки удваивайте. Табличные редакторы обычно делают это автоматически при экспорте в CSV UTF-8.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
Скачать пример CSV

Проверка

Не более 10 МБ и 20 000 записей. Пустые оригиналы или значения и повторяющиеся оригиналы в одном файле отклоняются. При поиске дублей регистр не учитывается, а пробелы нормализуются. Исправьте файл и импортируйте снова.

Управление

Откройте словарь для поиска и редактирования записей. Можно изменить название, включить или отключить словарь, заменить файл или удалить словарь. На страницах совпадения из активных пользовательских словарей имеют приоритет над встроенным словарём; название вашего словаря отображается как источник.

निजी शब्दकोश: JSON और CSV गाइड

सेटिंग्स → निजी शब्दकोश में शब्दकोश जोड़ें, नाम लिखें (जैसे “1,000 आवश्यक शब्द”), मूल और अर्थ की भाषाएँ चुनें, फिर JSON या CSV फ़ाइल चुनें। नाम और भाषाएँ ऐप में सेट करें, फ़ाइल में नहीं।

फ़ील्ड

original और meaning में खाली न होने वाला टेक्स्ट अनिवार्य है। example में उदाहरण वाक्य वैकल्पिक है। type वैकल्पिक है: word या idiom। इसे न देने पर मूल में खाली स्थान हो तो उसे वाक्यांश, अन्यथा शब्द माना जाता है। किसी भी भाषा के लिए फ़ील्ड नाम अंग्रेज़ी में बिल्कुल उदाहरण जैसे रखें।

JSON प्रारूप

ऑब्जेक्ट की सूची को UTF-8 .json फ़ाइल में सहेजें। टिप्पणियाँ या अंतिम आइटम के बाद अतिरिक्त कॉमा न डालें। उदाहरण में अंग्रेज़ी मूल और कोरियाई अर्थ हैं; अपनी चुनी भाषाओं का टेक्स्ट डालें।

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"

CSV प्रारूप

कॉमा से अलग की गई CSV UTF-8 (.csv) फ़ाइल सहेजें और पहली पंक्ति में कॉलम नाम रखें। original और meaning अनिवार्य हैं; example और type कॉलम छोड़ सकते हैं। कॉमा, उद्धरण चिह्न या नई पंक्ति वाले मान को दोहरे उद्धरण चिह्नों में रखें। अंदर के दोहरे उद्धरण चिह्न को दो बार लिखें। स्प्रेडशीट ऐप CSV UTF-8 निर्यात में आम तौर पर यह अपने आप करते हैं।

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom
CSV उदाहरण डाउनलोड करें

जाँच

फ़ाइल अधिकतम 10 MB और 20,000 प्रविष्टियों की हो। खाली मूल या अर्थ और एक फ़ाइल में दोहराए गए मूल स्वीकार नहीं होते। दोहराव की जाँच में बड़े-छोटे अक्षर समान माने जाते हैं और खाली स्थान सामान्य किए जाते हैं। फ़ाइल सुधारकर फिर आयात करें।

प्रबंधन

प्रविष्टियाँ खोजने और बदलने के लिए शब्दकोश खोलें। नाम बदल सकते हैं, चालू या बंद कर सकते हैं, फ़ाइल बदल सकते हैं या शब्दकोश हटा सकते हैं। पृष्ठों पर सक्रिय निजी शब्दकोश की मेल खाती प्रविष्टियों को अंतर्निहित शब्दकोश से प्राथमिकता मिलती है और आपके शब्दकोश का नाम स्रोत के रूप में दिखता है।

القاموس الشخصي: دليل JSON وCSV

في الإعدادات ← القواميس الشخصية، أضف قاموسًا وأدخل اسمًا (مثل «1000 كلمة أساسية»)، واختر لغتي النص الأصلي والمعنى، ثم ملف JSON أو CSV. يُضبط الاسم واللغات في التطبيق لا في الملف.

الحقول

يجب أن يحتوي original وmeaning على نص غير فارغ. example جملة مثال اختيارية. type اختياري وقيمته word أو idiom. عند حذفه، يُصنّف النص الأصلي الذي يحتوي على مسافات كتعبير، وإلا فككلمة. استخدم أسماء الحقول الإنجليزية كما هي مهما كانت اللغة المختارة.

تنسيق JSON

احفظ مصفوفة من الكائنات في ملف .json بترميز UTF-8، دون تعليقات أو فواصل زائدة في النهاية. المثال يتضمن نصوصًا أصلية بالإنجليزية ومعاني بالكورية؛ استبدلها بنصوص بلغاتك المختارة.

[
  {
    "original": "apple",
    "meaning": "사과",
    "example": "I eat an apple.",
    "type": "word"
  },
  {
    "original": "look after",
    "meaning": "돌보다",
    "example": "Please look after my bag.",
    "type": "idiom"
  }
]
تنزيل مثال JSON

تنسيق CSV

احفظ الملف بتنسيق CSV UTF-8 (.csv) مفصول بفواصل مع صف عناوين. عمودا original وmeaning إلزاميان؛ يمكن حذف example وtype. ضع القيم التي تحتوي على فواصل أو علامات اقتباس أو أسطر جديدة بين علامتي اقتباس مزدوجتين. ضاعف علامة الاقتباس داخل القيمة. تُجري برامج جداول البيانات ذلك عادةً عند التصدير بصيغة CSV UTF-8.

original,meaning,example,type
apple,사과,I eat an apple.,word
look after,돌보다,Please look after my bag.,idiom

التحقق

الحد الأقصى 10 MB و20,000 إدخال. تُرفض النصوص الأصلية أو المعاني الفارغة وتكرارات النص الأصلي داخل الملف الواحد. يتجاهل فحص التكرار حالة الأحرف ويوحّد المسافات. صحّح الملف واستورده مجددًا.

الإدارة

افتح القاموس للبحث عن الإدخالات وتعديلها. يمكنك إعادة تسميته وتفعيله أو تعطيله واستبدال ملفه أو حذفه. في الصفحات، تتقدم المطابقات في القواميس الشخصية المفعّلة على القاموس المدمج، ويظهر اسم قاموسك كمصدر.
